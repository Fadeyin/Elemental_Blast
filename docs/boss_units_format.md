# Формат `boss_units` в JSON уровня

Опциональный массив **`boss_units`** в корне файла уровня (`levels/level_XXX.json`). Каждый элемент — прямоугольный **босс** из одной текстуры монстра, общий пул HP.

## Поля элемента

| Поле       | Тип   | Описание |
|------------|-------|----------|
| `anchor_x` | int   | Колонка левого верхнего угла (0 … `cols`-1). |
| `anchor_y` | int   | Ряд верхнего левого угла в зоне врагов (0 … `enemy_rows`-1 в данных уровня; в игре зона врагов 10 рядов). |
| `width`    | int   | Ширина в клетках, ≥ 1. |
| `height`   | int   | Высота в клетках, ≥ 1. |
| `hp`       | int   | Общее HP босса, ≥ 1. |
| `sprite`   | int   | Необязательно. Индекс текстуры монстра (`1` … `5`), по умолчанию `1` — как монстр первого уровня. |

## Правила

- Прямоугольник **не должен выходить** за границы поля врагов и не пересекать **стены** и **разрушаемые препятствия** в занятых клетках (при инициализации клетки очищаются под босса).
- Стартовые монстры (`start_monsters`) в тех же клетках, что и босс, **перезаписываются** боссом (босс обрабатывается после стартовой расстановки).
- Цель уровня для босса учитывается **один раз** (одна «цель» в панели целей для этого босса).

## Пример (босс 2×2, текстура ур. 1)

```json
"boss_units": [
  {
    "anchor_x": 2,
    "anchor_y": 1,
    "width": 2,
    "height": 2,
    "hp": 24,
    "sprite": 1
  }
]
```

# Шлем Морта (Win Streak) — реализация GDD 4.0

Документ описывает фактическую реализацию фичи «Шлем Морта» в кодовой базе. Соответствие GDD проверяется по разделам ниже.

## Назначение

Шлем Морта мотивирует игрока проходить уровни подряд без поражений. За серию побед игрок получает стартовые бонусы — стрелы и бомбы — на поле следующего уровня. Поражение или ручной выход после совершённого валидного хода сбрасывают серию.

Используется только термин **«стрела»** (синоним «ракета» не применяется).

## Состояния фичи

| Состояние | Условие | Что видит игрок |
|-----------|---------|-----------------|
| Закрыто | `mort_helmet_unlocked == false` (до первой победы на 10 уровне) | В брифинге плашка Шлема Морта не отображается. |
| Стадия 0 | `mort_helmet_unlocked == true`, `win_streak == 0` | Плашка Шлема видна, бонусы не выдаются. |
| Стадия 1–3 | `win_streak >= 1` | Плашка с активными ячейками стадии и бонусами. |

## Условия открытия

- Фича открывается только после победы на уровне `MORT_HELMET_UNLOCK_LEVEL = 10`.
- Победа на 10 уровне сразу устанавливает стадию 1.
- Первые бонусы стадии 1 выдаются на старте 11 уровня.
- При первом открытии плашки в `level_start_dialog.gd` показывается короткий нежесткий туториал (`_maybe_show_mort_helmet_tutorial`).

## Стадии и награды

Реализовано в `LevelManager.get_mort_helmet_bonus_chips()`:

| Стадия | win_streak | Награда на старт уровня |
|--------|------------|-------------------------|
| 0 | 0 | — |
| 1 | 1 | 1 стрела + 1 бомба |
| 2 | 2 | 2 стрелы + 2 бомбы |
| 3 | 3+ (cap) | 3 стрелы + 3 бомбы |

`win_streak` ограничен сверху значением `MORT_HELMET_MAX_STAGE = 3`.

## Логика прогресса

Реализовано в `LevelManager.gd`:

- `mark_level_completed()` — победа. До открытия фичи победы не увеличивают серию; победа на 10 уровне открывает фичу и ставит стадию 1; последующие победы повышают стадию до 3.
- `mark_level_failed()` — поражение и отказ от продолжения. Серия → 0, стадия → 0. Флаг открытия фичи не сбрасывается.
- `mark_level_exited_after_valid_move()` — ручной выход после валидного хода. Серия сбрасывается.
- `mark_level_exited_without_move()` — выход без валидного хода. Серия сохраняется.

Покупка продолжения (refill) и итоговая победа сохраняют серию автоматически: серия сбрасывается только в `_on_defeat_no_lives_to_menu`, не вызываясь при оплаченном refill.

Валидный ход регистрируется в `game_board.gd` функцией `_register_valid_player_move()` после:

- успешного `_pop_cluster` (`popped > 0`),
- использования любого внутриигрового бустера через `_use_booster_on_cell`.

Простое открытие диалогов или меню валидным ходом не считается.

## Выдача бонусов на поле

Реализовано в `game_board.gd` (`_spawn_bonus_chips_at_start`, `_place_bonus_chips_in_valid_cells`).

1. Сначала размещаются выбранные предуровневые усиления.
2. Затем — бонусы Шлема Морта в оставшихся валидных клетках.
3. Если валидных клеток меньше, чем бонусов Шлема — лишние сохраняются в `_pending_mort_helmet_bonuses` и выдаются позже.
4. Каждое размещение сопровождается анимацией `scale` через `_active_anims`.

Валидная клетка для бонуса (`_is_valid_mort_helmet_cell`):

- находится в зоне игрока (`y >= ENEMY_ROWS`);
- содержит обычную цветную фишку (`chips[y][x] >= 0`);
- не имеет уже размещённой бонусной фишки;
- не участвует в активной анимации.

Отложенная выдача (`_try_deliver_pending_mort_helmet_bonuses`) вызывается после каждого валидного действия игрока и перед обновлением UI.

## Интерфейсы

`level_start_dialog.gd`:

- До открытия фичи плашка Шлема Морта **не показывается** — отображаются только цели и предуровневые усиления.
- После открытия отображается плашка с заголовком, тремя ячейками стадий, описанием бонуса и кнопкой «i».
- Кнопка «i» открывает окно правил (`_show_mort_helmet_rules`) с тремя стадиями наград и текстом «Поражение или выход после хода сбрасывают серию».
- Туториал (`_maybe_show_mort_helmet_tutorial`) затемняет экран, подсвечивает плашку и стрелкой указывает на «i». Тап по затемнению закрывает туториал. После первого показа флаг `mort_helmet_tutorial_shown` сохраняется.

`level_end_dialog.gd` (`_append_mort_helmet_progress_panel`): на экране победы показывается панель «ШЛЕМ МОРТА ОТКРЫТ!» при первом срабатывании или «СТАДИЯ X → Y» при росте. На стадии 3 рост не показывается (по GDD это допустимо).

## Сохранение

В `user://progress.cfg`, секция `[mort_helmet]`:

```
[mort_helmet]
unlocked=true
tutorial_shown=true
level=2
win_streak=2
```

При загрузке: если `unlocked == false`, серия и стадия принудительно обнуляются (защита от рассинхронизации).

## Аналитика

`LevelManager._log_analytics_event(event, payload)` пишет события в лог. Текущая реализация — `print` с префиксом `[Analytics]`; реальный трекер подключается одной точкой.

| Событие | Когда отправляется |
|---------|--------------------|
| `mort_helmet_unlocked` | Победа на 10 уровне открыла фичу. |
| `mort_helmet_tutorial_shown` | Игрок впервые увидел туториал. |
| `mort_helmet_rules_opened` | Игрок открыл окно правил. |
| `mort_helmet_stage_up` | Стадия Шлема выросла. |
| `mort_helmet_bonus_spawned` | Бонусы выданы на поле (с разбивкой `arrow`/`bomb`). |
| `mort_helmet_bonus_delayed` | Бонусы попали в очередь отложенной выдачи. |
| `mort_helmet_progress_lost` | Серия сброшена (поражение или выход после хода). |
| `mort_helmet_exit_without_loss` | Игрок вышел без валидного хода — серия сохранена. |

## Edge cases (соответствие GDD §11)

- Победа на 10 уровне → фича открывается, стадия = 1, бонусы появятся на 11 уровне.
- Поражение + покупка refill + победа → серия сохраняется (mark_level_failed не вызывается).
- Поражение + отказ от продолжения → `mark_level_failed`, стадия = 0, флаг открытия сохранён.
- Ручной выход без валидного хода → `mark_level_exited_without_move`, серия сохраняется.
- Ручной выход после валидного хода → `mark_level_exited_after_valid_move`, серия сбрасывается.
- Нет валидных клеток для бонусов → `_pending_mort_helmet_bonuses` ждут появления подходящих клеток.
- Предуровневые усиления заняли часть поля → Шлем выбирает другие валидные клетки (бонусы не наслаиваются).
- Стадия уже 3 → `win_streak` не растёт выше 3, награда стадии 3 выдаётся перед каждым следующим уровнем.

- Кампания: 50 файлов `levels/level_001.json` … `level_050.json`; «порталы» = `scheduled_spawns` с `y: 0`. Перегенерация: `python3 tools/generate_campaign_levels.py` (assert `assert_wall_row_gaps`; `enforce_wall_row_gaps` — плотные ряды стен чередуют проход слева/справа по порядку y — «змейка»). - Обход препятствий врагами: `_find_detour_exit_column_below_obstacle` + `_horizontal_detour_direction_order` — при блоке снизу порядок шагов влево/вправо к ближайшей колонке с проходом под связной группой `obstacles`.
- Level 1 tutorial: overlay `scripts/level1_tutorial_overlay.gd`, `game_board.gd`; запускается при каждом старте уровня 1 (без сохранения «уже показано»).
- Верхний тултип уровня (`game_board.gd`): по центру `MonstersRemainingPanel` — портрет слева, фиолетовая панель справа; подпись «Осталось\\nмонстров» 22px; «Назад» — оверлей на `UIRoot`, не в TopBar HBox.
- Внутриуровневые бустеры UI: кнопка 112 / иконка 100, `BoosterCluster` separation 24; без подложки. Не использовать `:=`/`var name` для путей кнопок — явные `String`.
- UI текст RU: `GameLabel`/`GameButton` (через `GameFonts`) — mixed Rubik; уважают `\n` и `autowrap_mode`; кнопки shrink-to-fit. Длинные подписи: `SIZE_EXPAND_FILL` + `AUTOWRAP_WORD_SMART` + `clip_contents`.
- Внутриуровневые бустеры: разблокировка по `LevelManager.current_level` — водный шар (HAMMER) 6, огненная стрела (ROW_BLAST) 7, вихрь (SHUFFLE) 13, корни (FREEZE) 14; `is_ingame_booster_unlocked_at_current_level`, в редакторе теста всегда открыты; туториалы на этих уровнях (`hammer_tutorial_shown`, `row_blast_tutorial_shown`, `shuffle_tutorial_shown`, `freeze_tutorial_shown` в `[boosters]`). Разовые +3 заряда (`ensure_ingame_booster_unlock_bonus_rewards`, `unlock_bonus_*`).
- Viewport layout (`game_board.gd`): корень **Node2D**. После 07.05.2026 убраны HTML5 viewport-эвристики как не корень серого экрана. `_get_layout_viewport_size()` снова использует `get_viewport_rect().size`, `get_viewport().get_visible_rect().size` и fallback из `project.godot`; `_board_pixel_origin()` = `_grid_origin(_get_layout_viewport_size())`; клики через `event.position`.
- Web export root cause 07.05.2026: серый экран после деплоя был из-за parse error autoload `LevelManager.gd`: ASCII-файлы `textures/Chip_*.png` были в git без `.import`, а код делал `preload("res://textures/Chip_Bonus_*.png")`. Добавлены `.import` для ASCII `Chip_Base_*` и `Chip_Bonus_*`; локальный Godot 4.6 headless Web export должен быть чистым по `SCRIPT ERROR|Parse Error`.
- Git: всегда пушить сразу в `main`, пока пользователь явно не попросит иначе (без отдельных веток по умолчанию).

- Level end: breach sets `_defeat_pending_breach`, stores attacker in `_pending_breach_monsters[column]`. After paid refill: restore hearts in attacked columns, `_increment_level_target` per pending, place pending monsters on heart row (or free cell), then `_shift_all_enemies_toward_spawn(REFILL_ENEMY_SHIFT_ROWS)` (1 row). No freeze on refill. Mixed columns: отключён ранний `continue` для столбцов с сердцем — иначе монстры над `_heart_row_y` не планировали ход и стояли (в т.ч. у стен). Спавн сверху в столбцах с сердцем по-прежнему отключён в `_apply_enemy_moves_from_plan`.
